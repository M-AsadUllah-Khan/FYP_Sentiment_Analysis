#  E-Commerce Sentiments Analysis System | FYP
**Intelligence Beyond Words | AI-Driven E-Commerce Sentiment Analysis**

## 📌 Project Overview
The **E-Commerce Sentiments Analysis System** is an advanced Natural Language Processing (NLP) dashboard designed as a Capstone Project. It automates sentiment analysis for the e-commerce sector, processing customer feedback and categorizing it into Positive, Negative, or Neutral sentiments. By decoding complex human emotions into visual, actionable metrics, it empowers businesses to proactively optimize product development and enhance customer satisfaction at scale.

## 🚀 Key Features
- **🔐 Secure Access Portal:** Robust login and registration system using SQLite, complete with strict password validation (Minimum 8 chars, 1 uppercase, 1 special character).
- **📊 Real-Time Telemetry:** Live dashboard metrics tracking the volume and percentage of overall sentiment predictions.
- **✍️ Manual Review Testing:** Instant sentiment classification for individual text inputs.
- **📁 Bulk Data Search:** Batch processing pipeline capable of analyzing thousands of reviews via CSV upload.
- **⚖️ Product Comparison:** AI-driven side-by-side sentiment comparison between competing products or brands.
- **🕒 Persistent Testing History:** Complete, timestamped logging of all user activity and past sentiment predictions in the backend database.
- **✨ Premium UI/UX:** State-of-the-art interface featuring Dark/Light mode support, glassmorphism components, and dynamic CSS animations.

## 💻 Tech Stack & Architecture
- **Language:** Python 3.x
- **Framework:** Streamlit (Frontend/Backend integration)
- **Database:** SQLite (Persistent data storage for users, usage, and history)
- **Data Manipulation:** Pandas
- **Styling:** Custom CSS injected globally for advanced animations and responsive layouts
