# AI Sentiments Analysis System | FYP
**Intelligence Beyond Words | AI-Driven E-Commerce Sentiment Analysis**

## 📌 Project Overview
The **AI Sentiments Analysis System** is an advanced Natural Language Processing (NLP) dashboard designed as a Capstone Project. It automates sentiment analysis for the e-commerce sector, processing customer feedback and categorizing it into Positive, Negative, or Neutral sentiments. By decoding complex human emotions into visual, actionable metrics, it empowers businesses to proactively optimize product development and enhance customer satisfaction at scale.

## 🚀 Key Features
- **🔐 Secure Access Portal (with OTP):** Robust login, registration, and account recovery system featuring strict password validation and real-time Email OTP verification.
- **☁️ Cloud Database Integration:** Powered by Neon PostgreSQL for enterprise-grade, secure, and real-time data syncing globally.
- **📊 Real-Time Telemetry:** Live dashboard metrics tracking the volume and percentage of overall sentiment predictions.
- **✍️ Manual Review Testing:** Instant sentiment classification for individual text inputs.
- **📁 Bulk Data Search:** Batch processing pipeline capable of analyzing thousands of reviews via CSV upload.
- **⚖️ Product Comparison:** AI-driven side-by-side sentiment comparison between competing products or brands.
- **🕒 Persistent Testing History:** Complete, timestamped logging of all user activity and past sentiment predictions in the cloud backend.
- **✨ Premium UI/UX:** State-of-the-art interface featuring Dark/Light mode support, glassmorphism components, and dynamic CSS animations.

## 💻 Tech Stack & Architecture
- **Language:** Python 3.x
- **Frontend Framework:** Streamlit
- **Backend API:** FastAPI
- **Database:** PostgreSQL (Neon Tech Cloud DB)
- **NLP Engine:** VADER Sentiment & TextBlob
- **Styling:** Custom CSS injected globally for advanced animations and responsive layouts
